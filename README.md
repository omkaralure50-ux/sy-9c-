# C++ Data Structures Practicals

---

# Repository Overview

This repository contains C++ practical assignments demonstrating fundamental Data Structures concepts including Stack, Queue, Linked List, Binary Tree, Binary Search Tree, and Graph operations.

The programs are menu-driven and allow users to perform different operations interactively.

---

# Practical 1 – Stack Implementation

## Overview

A menu-driven Library Stack Management System that demonstrates the implementation of a Stack using an array.

## Features

* Return Book (Push)
* Arrange Book (Pop)
* View Top Book (Peek)
* Display Books in Stack
* Stack Overflow Handling
* Stack Underflow Handling

## Concepts Used

* Stack Data Structure
* Arrays
* Classes & Objects
* Constructors
* LIFO (Last In, First Out)
* Push Operation
* Pop Operation
* Peek Operation
* Overflow & Underflow
